# Third-party dependencies

The application artwork is generated by the source in this project.
No external illustration, CDN font, image or environmental audio is required.

Runtime dependencies:
- React: MIT
- React DOM: MIT
- GSAP: GSAP Standard License
- `@fontsource/caveat`: SIL Open Font License 1.1 (bundled locally into `dist/assets/`)

Server-side weather data (optional opening preview via `api/scene-context.ts`):
- Open-Meteo Forecast API (`https://api.open-meteo.com/v1/forecast`): Free tier is licensed for non-commercial use with attribution (`Weather data by Open-Meteo.com`, CC BY 4.0). Commercial distribution requires a paid Open-Meteo licence or commercial weather provider.

Development dependencies:
- Vite: MIT
- Vite React plugin: MIT
- TypeScript: Apache-2.0
- Vitest: MIT
- Playwright: Apache-2.0
- Type declarations: retain the licences included in their packages

GSAP is not identified here as MIT or as an OSI-licensed dependency.
Review the licence included with the installed package.

The recording and lyrics have rights separate from application source.
The project does not grant permission to distribute either.

Retain dependency licence notices and commit the reviewed lockfile.
