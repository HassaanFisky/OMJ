# Authorized audio

Place the final authorized recording here, for example:

audio/omj.mp3

Set VITE_AUDIO_SOURCE=/audio/omj.mp3 in the project environment.

Alternatively, use the application's local audio picker.
A selected local file is not uploaded.

Do not download or extract the recording from streaming references.
Do not commit or deploy a recording without appropriate authorization.

The recording's actual metadata determines duration.
